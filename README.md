# MyNomadToolkit

MyNomadToolkit is a US virtual phone number, online fax, and travel eSIM service for remote workers, freelancers, independent businesses, and long-term travelers.

One account for a US number with call forwarding and voicemail, online fax without a machine, and travel eSIM data for 198+ countries.

This repository is the public brand and documentation entry point. Product code is maintained privately.
